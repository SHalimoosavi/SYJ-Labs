# SYJ LABS — GitHub Pages portfolio

A responsive, static portfolio for SYJ LABS using HTML, CSS and vanilla JavaScript.

## Publish
1. Create or open `SHalimoosavi/SYJ-Labs`.
2. Upload the contents of this folder to the repository root (not the enclosing ZIP/folder).
3. Commit to `main`.
4. Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
5. Wait for the Pages deployment, then verify `https://shalimoosavi.github.io/SYJ-Labs/`.

## Before publishing
- Confirm the YouTube QR code resolves to the intended SYJ LABS channel. The QR image is included as supplied. The text link currently points to YouTube's home page until you replace it with the exact channel URL.
- Google Search Console: add the site property `https://shalimoosavi.github.io/SYJ-Labs/`, choose HTML tag verification, copy the real token into the `google-site-verification` meta tag in `index.html`, commit, and click Verify. Do not leave the placeholder token if using HTML-tag verification.
- Confirm the canonical URL and sitemap URL match the final Pages URL.
- Check repository links and project descriptions against current READMEs. Where a direct repository slug was not confirmed, the card links to the GitHub profile rather than a guessed repo.
- Images are illustrative workspace visuals provided for the page, not evidence of actual employees, products, or shipped interfaces.
